第一版只回答「貓咪為什麼喜歡躲紙箱？」。五篇來源、三項獨立原始研究，依序建立來源摘要、概念與主題綜合，再做成八頁教學簡報。重要主張可回查來源，不將收容所結果推廣成每隻家貓的反應。

直接以瀏覽器開啟 index.html，或使用上方 GitHub Pages 網址。無需 API 金鑰。內部圖片與字型已附在專案中，外部文獻需要網路。
